# Repository Rules

## Privacy & Git Sanitization
- Never commit hardcoded local machine paths or local user directories (e.g. `/home/<user>/...` or `file:///home/...`).
- Use relative paths (e.g. `docs/screenshots/...`) or GitHub asset URLs for media and screenshots.
- Public GitHub repository URLs and clone commands should use the repository's GitHub owner/repo name (e.g. `https://github.com/hugorobert84/...`), but never local filesystem paths.
